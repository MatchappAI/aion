# AION (local): application overview

**What it is.** Mohil Gupta's own acquisition and value-creation system for a holding company that buys specialized B2B professional and technical services firms (thesis v3.0 in `lib/thesis.mjs`). It runs on this Mac in a browser tab, with the AI chosen in Settings.

**Who uses it.** The founder and interns, plus live demos for investors and sellers.

**Business outcome.** Find firms to buy before brokers list them, find clients and people for portfolio firms, turn a seller's books into real EBITDA and a sized plan, and draft RFP answers and candidate write-ups, all with every number traceable to the books or a source link.

**Tools (top tabs)**
| Tab | What it does |
|---|---|
| Value Creation | Upload a General Ledger, P&L Detail or PDF/CIM → real EBITDA, AION fit (thesis check), ranked plan and 100 days, trends, deal returns, monthly check-in, 1-page PDF and Excel |
| Proprietary Search | Find firms to buy, clients for a firm, or people for a role: 20–40 web searches, in-depth checks, sources, contacts, timing signals, deal pipeline, weekly watch, demand radar |
| Documents | Draft an RFP answer or a candidate write-up |
| Settings | Which AI does the work: Claude Code first, Codex or an API key as backups |
| Help | How to use each tool and fixes for common problems |

**Status:** working, tested; see `TEST_RESULTS.md` and `KNOWN_LIMITATIONS.md`. Sibling product: the partner editions for Partner A and Partner B (`~/Desktop/AION/partner-editions`), which share most of this code.
