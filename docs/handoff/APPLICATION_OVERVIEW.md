# AION (local): application overview

**What it is.** Mohil Gupta's own acquisition and value-creation system for a holding company that buys US ecommerce consulting firms: retail placement, marketplace agencies, and ecommerce strategy & analytics (thesis v4.0 in `lib/thesis.mjs`). It runs on this Mac in a browser tab, with the AI chosen in Settings.

**Who uses it.** The founder and interns, plus live demos for investors and sellers.

**Business outcome.** Find ecommerce consulting firms to buy (full buyout or majority stake) before brokers list them, contact the owners personally with your OK on every send, and turn a seller's books into real profit, a price and the questions to ask, with every number traceable to the books or a source link.

**Tools (top tabs)**
| Tab | What it does |
|---|---|
| Search & Outreach (first tab) | Owners to contact (one ranked list); find firms to buy or brands that need retail or marketplace help: 20–40 web searches, in-depth checks, sources, contacts, timing signals, deal pipeline, weekly watch, brand demand radar; personal drafts, confirmed sends, replies and opt-outs from Gmail |
| Value Creation | Upload → Real profit → Price & returns → Questions: a General Ledger, P&L Detail or PDF becomes real profit, a price against the price guide, a plan and the seller questions; 1-page PDF and Excel |
| Settings | Which AI does the work: Claude Code first, Codex or an API key as backups |
| Help | How to use each tool and fixes for common problems |

**Status:** working, tested; see `TEST_RESULTS.md` and `KNOWN_LIMITATIONS.md`.
