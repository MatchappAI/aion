# Known limitations

1. **API-key engines not tested live** (no keys on this Mac). Claude Code and Codex detection and the Claude Code Test were verified; Codex usage was exhausted until November 23, 2026 during testing.
2. **Watch weekly runs only while AION is running.** A due watch runs within 30 minutes of the next start.
3. **AI plan values vary between runs**; saved answers make re-opens stable. "Run the AI again" replaces them.
4. **PDF statements give totals only** (no customers, collections or monthly trends).
5. **1-page PDF needs Google Chrome** in /Applications.
6. **Mac only as packaged** (`Start AION.command`); on other systems run `npm start`.
7. **Single user, single computer**; copy `workspace/` to move or back up.
8. The **Plan tab's "What we could build next"** list and the Search page's agents list describe tools not built yet. They are labelled "not built yet" on purpose for investor demos.
