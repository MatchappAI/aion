# How to use AION (local)

Start it by double-clicking `Start AION.command`; it opens http://localhost:8765. The same steps are in the app under **Help**.

## Settings: which AI
Claude Code is used first when logged in. Add Codex (`codex login`) or an Anthropic/OpenAI key as a backup; when one hits its usage limit the next takes over for an hour. **Test** sends a tiny request. **Use this** pins one; **Go back to automatic** undoes it.

## Value Creation
1. Leave **Hide customer and staff names from the AI** ticked (default) unless you need names in the prompts.
2. Drop the books: QuickBooks **General Ledger** (24–36 months, all accounts, Excel) is best; **P&L Detail** or a **PDF / CIM** also work.
3. Watch the five steps (under a minute when saved answers exist; a few minutes otherwise).
4. Read the tabs:
   - **Overview:** reported → real EBITDA → each change → could reach. Answer the biggest unknown (is that payroll line the owner?).
   - **AION fit:** thesis check PASS/WATCH/FAIL/NEEDS DATA with evidence, tool fit, dated diligence answers.
   - **Plan:** ranked actions, five-part value table, 100 days, "grow to a target multiple" model. **Build it** gives steps and a copyable prompt.
   - **Trends** (ledger uploads), **Deal** (price, loan, vehicles, returns; a loss-maker can be priced on revenue), **After you buy** (monthly books vs plan), **Questions & checks**.
5. **1-page PDF** (needs Chrome) and **Excel** save to Downloads; a corner message confirms.
6. **Make the plan sharper:** add a payroll or sales-by-customer report.
7. Deal tabs across the top: click to switch, double-click to rename, **+ New deal**. **Close this deal** archives it; nothing is deleted. **Run the AI again** ignores saved answers.

## Proprietary Search
1. Pick **Find firms to buy**, **Find clients**, or **Find people**. Type a sentence or click an example; optional filters.
2. **Search** (4–8 minutes; two can run at once). Watch the steps or come back later.
3. Results: fit score, timing badge, every fact with its link, verified contacts. **Save / Priority / Reject**, notes, **Deal stage**, **Watch weekly** (runs while the app is open), **Refresh data signals**, linked searches (clients for a firm, people for a role).
4. Home page: **Who to call this week**, deal pipeline, watched searches, history, **your network**, **Demand radar** (scan a region for buying signals), data sources (upload your contacts CSV to see warm introductions).

## Documents
- **Answer an RFP:** upload or link the RFP; AION drafts each section in the order asked, highlighting what needs your input.
- **Candidate write-up:** pick a candidate from a search or upload a résumé, plus a job order.
- Drafts only; you edit and send.
